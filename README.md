# OpenDataFlow

An end-to-end data engineering portfolio project built with
Python, PostgreSQL, Apache Airflow, Docker, and automated tests.

## Project Goals

- Extract public transportation data.
- Validate and transform raw data.
- Store structured data in PostgreSQL.
- Orchestrate pipeline tasks with Apache Airflow.
- Test data quality and pipeline behavior.
- Document the architecture and setup.
